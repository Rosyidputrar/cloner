# Kembar

Kembar is an Android app for running a second, isolated instance of apps you already have
installed (for example a second WhatsApp or Instagram account). Each clone has its own data,
login, cache and notifications, and is always visibly marked as a clone.

Status: **design phase**. No code yet.
