# Roadmap

Each phase ends with: build instructions, real-device test steps, known limitations, and a
manual checklist. Work stops after each phase until the owner replies **"lanjut"**.

| Phase | Scope | Exit criteria |
|-------|-------|---------------|
| **1. Project setup + design system** | Gradle 8.7 wrapper, version catalog, `build-logic` convention plugins, Hilt, DataStore, detekt + ktlint, JUnit 5. `:core:ui` design system (color tokens light/dark/dynamic, type scale, spacing, shapes, motion, state views, clone badge, stage indicator). Splash, Onboarding (4 slides), Disclaimer, adaptive navigation shell, Beranda (empty state), Pengaturan (theme), Tentang. | `./gradlew assembleDebug assembleRelease testDebugUnitTest lintDebug detekt ktlintCheck` green. |
| **2. App list (Pilih Aplikasi)** | Launchable apps, search, filter, sort, icon/version/size, compatibility hints (analyzer rules that need no engine), all UI states. | Picker usable at 200% font scale and with TalkBack. ViewModel + Compose tests. |
| **3. Clone engine core** | `:engine:api`, `:engine:impl` (StringPool, AxmlPatcher, ArscPatcher, AlignedZipWriter, FileKeystore, CloneSigner, ApkInstaller, CloneAnalyzer, CloneEngine), `:core:database`, `CloneWorker`, Proses Clone screen with 5 stages + cancel. Host tests with aapt2/d8 fixtures verified by apksigner/zipalign. Spikes S1–S4. | A fixture app and at least one real app (e.g. Telegram) cloned twice and launched on a device. Spike results recorded. |
| **4. Clone manager + shortcuts** | Beranda list, Detail Clone: launch, rename, icon + badge, pinned shortcut via lock-aware trampoline, clear data (App Info), uninstall. Spike S6 (icon badge). | All actions work on a real device. Destructive actions confirmed. |
| **5. Health, updates, backup** | `HealthCheckWorker`, `UpdateCheckWorker` (`getChangedPackages`), update/repair as reinstall-with-same-key, notifications, per-clone settings (notifications deep link, permissions, storage, network per S7), encrypted backup of settings + keys and restore. Spike S5. | Clone survives an original-app update via "Perbarui clone" with data kept. Backup restores on a second device and the restored key updates an existing clone. |
| **6. Security hardening + polish** | Threat model doc, exported-component audit, app lock (Kunci Aplikasi), Bantuan, "Aplikasi yang tidak bisa di-clone", permission rationale screens, copy and accessibility audit. | Threat-model mitigations implemented or explicitly accepted. Accessibility checklist passes. |
| **7. Tests + CI + release** | Coverage gaps, Room migration tests, baseline profile, R8 verification on release, GitHub Actions (build, lint, detekt, ktlint, unit tests, assembleRelease), release signing via secrets, release checklist, license. | Tagged release APK built by CI. |
